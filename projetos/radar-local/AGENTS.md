# Radar Local

> Projeto interno criado em 2026-08-05. As instruções deste arquivo complementam as regras da raiz.

## Sobre

Criar uma área privada para Gabriel registrar, organizar e acompanhar empresas pesquisadas durante a prospecção comercial da Krake Digital.

## Tipo

Projeto interno.

## Entregas previstas

- Sistema web responsivo
- Área privada com autenticação
- Cadastro e edição de empresas
- Fila de contatos e acompanhamento comercial
- Base persistente de empresas pesquisadas

## Onde salvar o que

- Briefing e decisões: raiz desta pasta
- Código e arquivos públicos: `site/`

## Contexto que herda da raiz

Este projeto herda o posicionamento, o tom de voz, a estratégia e a identidade visual definidos em `_memoria/` e `identidade/` na raiz do workspace.

## Específico deste projeto

- Usar a mesma stack do site da Krake: Next.js App Router, React, TypeScript estrito, Tailwind CSS e shadcn/ui.
- Tratar os registros de empresas como dados privados.
- Permitir editar todos os campos de uma empresa já cadastrada.
- Priorizar ações rápidas para WhatsApp, Google Maps, site e Instagram.
- Não inventar dados de empresas na versão final; dados demonstrativos devem ser claramente identificados.
